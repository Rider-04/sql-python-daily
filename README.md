# SQL + Python Daily Practice

Daily SQL & Python practice using the **MySQL Sample Database** (classic model: `productlines`, `products`, `orderdetails`, `orders`, `customers`, `employees`, `offices`, `payments`) — progressing from basics to advanced, one day at a time.

I learned SQL and Python for Data Science a few months ago and started noticing rust setting in. This repo is my daily practice log to stay sharp — a mix of query writing, data manipulation, and analysis, tracked day by day.

## Structure

```
sql-python-daily/
├── README.md
├── sql/
│   ├── day1.sql
│   ├── day2.sql
│   └── ...
└── python/
    ├── day1.ipynb
    ├── day2.ipynb
    └── ...
```

- **`sql/`** — one `.sql` file per day, each question followed by its answer query.
- **`python/`** — one Jupyter notebook per day, using pandas/numpy/matplotlib/seaborn on the same dataset .

## Dataset

This practice uses the **MySQL Sample Database** (a.k.a. `classicmodels`), a well-known sample dataset simulating a scale-model car dealer, with tables for products, orders, customers, employees, offices, and payments.

- Schema reference: [MySQL Sample Database Diagram](https://www.mysqltutorial.org/mysql-sample-database.aspx)
